# Plant Leaf Disease Classifier

Upload a leaf photo to get the predicted disease class, confidence, and a Grad-CAM overlay.

**Educational demo only — not for field diagnosis.**

Trained on PlantVillage (EfficientNet-B0 + color jitter). Best on lab-style single-leaf photos.

**Covers course P11**
